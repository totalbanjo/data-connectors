Projection contract: invalid baseline/materialization/retention/cleanup/authority or timeout/signal/malformed output → `inconclusive`; unknown or validated `not_exercised` reachability → `inconclusive`; recognized focused assertion failure → `killed` with optional `not_run_focused_kill`; focused pass + attributable backstop failure → `killed, selectorMiss: true`; both pass → `survived` pending triage. Contradictory full normalized outcomes on one trial key → `inconclusive`; never retry automatically.

**Source gaps found by reading H, not execution:** `judgeIdentityFor` hashes names/IDs, not judge bytes; the batch deadline is checked only between operators; focused nonzero exits are broadly called test failures; no separate clean focused execution is recorded; `runCompleteBackstop` omits `env`. The two-hour constant is not a demonstrated reuse validator. Do not repeat stronger comments/tasks as code guarantees.
The destination adapter must first reproduce those gaps with deterministic fixture probes, then bind actual judge/policy/lock bytes and commands, run clean focused evidence, pass isolated environment through authority, classify only recognized owning assertions, enforce direct-output limits before buffering and enforce the remaining batch deadline across install/focused/authority phases. These are declared behavior changes in the existing adapter files, with a destination policy version; preserve raw failure evidence and quarantine on interruption. Retain failed/incomplete accounting artifacts before disposing a clone, labelled unverified observations; never relabel them successful receipts.
Keep full-backstop authority rejection **inconclusive** in this PR, matching H's actual runner. `runAuthority` rejects failed suites; no exported outcome-neutral quartet verifier exists, and the copy helper cannot replace one. Thus the selector-miss table remains covered as a pure contract, but this port does not claim end-to-end selector-miss attribution. Adding that capability would require an explicit independently reviewed adapter verifier; do not infer it from an error string. This limitation belongs in the destination memo, not an invisible “preserved” claim.
